# Unified Video Maker Pipeline Guide

This skill documents the full architecture, operating procedures, and technical specifications of the **Unified Video Maker** pipeline. It covers both long-form (16:9) and short-form (9:16) rendering in Hindi and English.

---

## 1. Pipeline Overview & 3-Stage Architecture

The pipeline processes raw narrative stories and audio voiceovers into fully rendered cinematic animated videos across 2 automated execution stages:

```
[story.txt + voiceover.*]
           │
           ▼
┌────────────────────────────────────────────────────────┐
│  STAGE 1: Complete Blueprint Generation                │
│  - Whisper word-level transcription                    │
│  - AI Word-level content sanitization                  │
│  - Character Pass (English traits)                     │
│  - Director Pass (Gemini / DeepSeek):                  │
│    • visual_prompt (Ghibli anime style, frozen action) │
│    • camera_movement (push_in, pan, tilt, etc.)        │
│    • transition_type (cut, dissolve, fade_to_black)    │
│    • transition_duration & scene duration              │
│    • Dynamic anti-repetition cinematography            │
│  - Music Pass (Multi-Emotion Cinematic Score)          │
│  - SFX Blueprint (Timestamped sound design cues)       │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  ASSET GENERATION & AUDIO PREVIEW                      │
│  - (Optional) test_audio.py: 3-5s audio mix preview    │
│  - Save visual assets: 1.jpg (or 1.mp4), 2.png, etc.   │
│  - Generate any missing emotional music in music/      │
│  - Generate any needed SFX in sfx/                     │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  STAGE 2: FFmpeg Cinema Rendering                      │
│  - Ken Burns ZoomPan (flicker-free dual scale)         │
│  - Mixed Image & Video Asset Support                   │
│  - Crossfade Transitions (xfade offset math)           │
│  - Multi-Track BGM Crossfade & Sidechain Ducking       │
│  - Dynamic SFX Bed Assembly & Peak Limiting            │
│  - ASS Word-Level Animated Captions                    │
└────────────────────────────────────────────────────────┘
```

## 2. Directory Structure & Asset Conventions

Projects are isolated in dedicated asset directories:
* `hindi_long_assets/` (Long-Form Hindi 16:9)
* `english_long_assets/` (Long-Form English 16:9)
* `hindi_short_assets/` (Shorts Hindi 9:16)
* `english_short_assets/` (Shorts English 9:16)

### Key Files in Each Project Folder:
* `story.txt` *(Input)*: Raw narrative text.
* `voiceover.mp3` / `.wav` / `.m4a` *(Input)*: Spoken voiceover track.
* `transcript.json` *(Generated)*: Whisper word-level timestamp array (`word`, `start`, `end`).
* `character_prompts.json` *(Generated)*: Character traits, age stages, and Studio Ghibli reference prompts.
* `video_blueprint.json` *(Generated)*: Master sequence of visual scenes (`scene_id`, `start_time`, `end_time`, `visual_prompt`, `sfx_id`, `camera_movement`, `transition_type`).
* `music_blueprint.json` *(Generated)*: Multi-emotion score timeline with narrative reasons, mood tags, and track mappings.
* `sfx_blueprint.json` *(Generated)*: SFX cues mapped to scene IDs and timestamp offsets.
* Assets *(Generated by user/AI)*: `1.jpg` (or `1.mp4`), `2.png`, etc., corresponding to each `scene_id`.

### Global Persistent Databases (Untracked in Git):
* `sfx/sfx.json`: Master library of sound effects across stories. Maps sound IDs to rich prompts. Completely untracked in Git so user descriptions are permanently preserved on Google Drive.
* `music/music.json`: Master library of emotional background tracks. Maps track IDs to emotions, descriptions, and audio filenames. Completely untracked in Git so custom music entries are never overwritten by code syncs.

## 3. Stage 1: Blueprint Generation Deep-Dive

### A. Word-Level Content Sanitization (`_sanitize_hindi_story_and_words`)
To prevent Google Gemini's automated `PROHIBITED_CONTENT` safety filter from blocking Hindi dramatic stories:
1. **In-Memory Replacement:** Identifies red-flagged Hindi dramatic keywords (*कर्ज़, कब्ज़ा, बर्बादी, खून, हथियार, फांसी*) and maps them to neutral English words (*loan, repossession, ruin, blood, weapon, despair*).
2. **DeepSeek Dynamic Scanner:** Uses DeepSeek via Together AI to scan the story and detect any story-specific trigger terms.
3. **Exact Timestamp Preservation:** Modifies only the `w["word"]` string in memory. All Whisper `start` and `end` millisecond timestamps remain 100% untouched.
4. **Disk Safety:** Does not overwrite `story.txt` or `transcript.json` on disk; sanitization occurs strictly in memory.

### B. Gemini with Clean Scrap-and-Restart DeepSeek Fallback
1. **Primary Engine:** Google Gemini Flash runs the Director Pass chunk-by-chunk (~180s per chunk).
2. **Clean Scrap-and-Restart:** If Gemini fails or gets blocked on *any* chunk (e.g. Chunk 2):
   * All partial scenes generated by Gemini are immediately scrapped.
   * Counters, contexts, and SFX registries are cleanly reset.
   * DeepSeek (`deepseek-ai/DeepSeek-V4.1-Flash`, backup `deepseek-ai/DeepSeek-V3`) takes over and executes the entire pass from Chunk 1 to completion.
3. **English Enforcement:** All character descriptions and visual prompts are strictly formatted in English with `ensure_ascii=False` so AI image generators receive clean prompts without Devanagari Unicode escape codes.

### C. Multi-Emotion Cinematic Music Pass
Instead of a single repetitive background track, the Music Pass analyzes the narrative arc:
1. **Emotional Segmentation:** Breaks the story into distinct emotional chapters (e.g., *Melancholic & Somber*, *Tender & Pensive*, *Cathartic Embrace*, *Warm & Hopeful*).
2. **Track Matching & Reuse:** Checks `music/music.json` for existing tracks matching the required emotion. If a matching track exists, it reuses it automatically.
3. **New Track Proposals:** If an emotion is missing, the AI proposes a dedicated track ID, BPM, instrumentation, and generation prompt in `music_blueprint.json` and registers it in `music/music.json`.
4. **Smooth Crossfades:** During rendering, tracks seamlessly crossfade at emotional transition boundaries without harsh audio cuts.

## 4. Cinematography & Anti-Repetition Rules (Stage 1 Embedded)

Camera movement, transition types, and timing are determined in Stage 1 by the AI Director:
* **Narrative Camera Assignment:**
  - *Close-up, portrait, emotional speech* $\rightarrow$ `push_in`, `zoom_in_left`, `zoom_in_right`.
  - *Wide scenery, establishing shots, departures* $\rightarrow$ `push_out`, `pan_left`, `pan_right`.
  - *Action, walking, character tracking* $\rightarrow$ `pan_left`, `pan_right`.
  - *High vertical structures, sky/ceiling gazing* $\rightarrow$ `tilt_up`, `tilt_down`.
* **Two-Layer Anti-Repetition Defense:**
  1. *Prompt-Level Rule:* Explicitly commands the LLM never to repeat the same camera movement twice consecutively.
  2. *Python Post-Processor:* Automatically verifies consecutive scenes and alternates movements (`push_in` $\rightarrow$ `pan_right` $\rightarrow$ `push_out` $\rightarrow$ `tilt_up`) if the LLM repeats.
* **Transition Logic:**
  - *Continuous dialogue or action in same setting* $\rightarrow$ `"cut"` (duration `0.0s`).
  - *Scene change, location move, or time passage* $\rightarrow$ `"dissolve"` (duration `1.0s`).
  - *Major chapter end, flashback, or cliffhanger* $\rightarrow$ `"fade_to_black"` (duration `1.0s`).
* **Retirement of Stage 2 Vision Pass:** Eliminates the 4.5 GB Qwen2-VL local download, saves 5+ minutes of processing time, avoids VRAM out-of-memory errors on Google Colab, and transitions directly to rendering once image assets are placed.

## 5. Instant Audio Mix Preview (`test_audio.py`)

A lightweight preview engine allowing creators to hear and approve the entire audio experience before generating visual images:
* **Execution Time:** ~3–5 seconds (pure FFmpeg audio processing, zero video rendering).
* **Auto-Detection:** Automatically locates `voiceover.mp3`, `voiceover.wav`, or `audio.*` across active asset directories.
* **Outputs:** 
  1. `/content/drive/MyDrive/Video_Projects/output/test_audio.mp3`
  2. `/content/drive/MyDrive/Video_Projects/test_audio.mp3` *(Root Google Drive folder for one-click access)*
* **Interactive In-Colab Playback:** Supports `IPython.display.Audio("test_audio.mp3")` for immediate browser playback.

## 6. Stage 2: FFmpeg Cinema Rendering Engine

### A. Ken Burns ZoomPan Filter
* Implemented in `py_files/renderer_long.py` (1920x1080) and `renderer_short.py` (1080x1920).
* **Flicker Prevention:** Pre-scales images up to `scale=4000:-1` (or `scale=-1:4000`), applies smooth sub-pixel zoompan expressions, forces steady frame rate (`fps=30`), and scales back down to final resolution.

### B. Mixed Media Support (Images + Video Clips)
* Accepts both still images (`.jpg`, `.png`, `.webp`) and video clips (`.mp4`, `.mov`).
* **Audio Stripping:** All input video clips automatically have their embedded audio stripped (`-an`) so they do not clash with the voiceover track.
* **Duration Handling:** If a video clip is shorter than the required scene duration, the renderer holds the final frame and continues with a smooth Ken Burns still zoom.

### C. Crossfade Math (`xfade`)
* Computes cumulative transition offsets to prevent audio/video drift:
  $$\text{offset}_i = \text{start\_time}_i - (i \times \text{crossfade\_duration})$$
* Transitions blend smoothly without clipping or black frames.

### D. Native Sidechain Ducking & Dynamic SFX Bed
The audio engine applies broadcast-standard multi-track mixing:
1. **Loudness Normalization:** Voiceover is normalized to broadcast standard (-14 LUFS):
   `[0:a]aresample=44100,loudnorm=I=-14:LRA=11:TP=-1.5,apad,asplit[vo_norm][vo_sc]`
2. **Native Sidechain Ducking (`sidechaincompress`):** Background music volume is dynamically dipped whenever the voiceover speaks, and gently swells during dramatic pauses:
   `[bgm_resampled][vo_sc]sidechaincompress=threshold=-20dB:ratio=2.5:attack=100:release=1000[bgm_ducked]`
   - *Attack (100ms):* Smooth, immediate dip when speech starts.
   - *Release (1000ms):* 1-second gentle swell filling silent narrative pauses.
3. **Dynamic SFX Alignment:** Sound effects from `sfx_blueprint.json` are delay-shifted to their exact scene timestamps using `adelay` and mixed into an SFX bed (`amix`).
4. **True Peak Limiting:** Mixed with `alimiter=limit=0.95` to prevent any audio clipping or distortion.

## 7. Execution Commands

### Long-Form Video (16:9):
```bash
python3 main-long.py
```
* Follow interactive CLI prompts to select language (Hindi/English).

### Short-Form Video (9:16):
```bash
python3 main-short.py
```

### Instant Audio Preview:
```bash
python3 test_audio.py
```

### Preflight / Environment Requirements:
* `GEMINI_API_KEY_FREE`: *(Optional)* Free-tier Gemini API key. Attempted first with 3 retries for ₹0 cost.
* `GEMINI_API_KEY`: Standard / paid Gemini API key. Used as automatic failover if free key is exhausted or unavailable.
* `TOGETHER_API_KEY`: Required for DeepSeek fallback and dynamic word sanitization.
* `ffmpeg`: Must be installed on the system path with `libx264` and filter support.
